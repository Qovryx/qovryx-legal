# Qovryx — informations légales publiques

Dépôt public réservé aux informations légales des applications Qovryx. Les produits et leurs dépôts de développement restent privés.

- Portail : `index.html`
- Lumhora : `lumhora/privacy/index.html`
- Pour un nouveau produit : `<produit>/privacy/index.html`, sans créer de dépôt supplémentaire.

Publication : GitHub Settings > Pages > Build and deployment > Deploy from a branch > main > /(root).

Adresse Pages prévue : https://qovryx.github.io/qovryx-legal/lumhora/privacy/

La page Lumhora s'appuie sur une inspection partielle du code. Vérifier le bundle final et les dépendances avant validation définitive des déclarations Google Play. Ne pas publier ici de clés, mots de passe, informations personnelles non destinées au public ou fichiers privés.
